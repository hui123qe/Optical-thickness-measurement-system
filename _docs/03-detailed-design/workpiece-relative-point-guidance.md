# 工件相对测点引导流程详细设计

## 1. 目标与坐标

客户给出物料坐标系中的测点 `Pw=(xw,yw)`，软件计算 XY 电机绝对目标坐标 `Q=(X,Y)`，使该物料点移动到固定激光探头下方。

本设计只使用：

- 物料相对坐标；
- 电机绝对坐标。

物料通过三根定位销安装，三销确定的物料中心作为物料坐标原点 `P0=(0,0)`。

## 2. 两点示教建立平移和角度

### 2.1 示教物料原点，得到平移量

1. 将物料中心 `P0=(0,0)` 移动到固定激光探头下方。
2. 记录此时的电机绝对坐标：

```text
Q0 = (X0,Y0)
```

标准齐次变换中的平移向量为：

```text
t = (tx,ty)ᵀ = (X0,Y0)ᵀ
```

其含义是：物料原点映射到电机坐标中的 `(X0,Y0)`。该坐标只用于建立矩阵，正常测量不需要先移动到 `Q0`。

### 2.2 示教物料 +X 方向点，得到映射角度

在物料 `+X` 方向选择一个已知点：

```text
P1 = (d,0)，d > 0
```

将 `P1` 移动到固定激光探头下方，记录电机绝对坐标：

```text
Q1 = (X1,Y1)
```

两个示教结果在电机坐标中的方向向量为：

```text
v = Q1 - Q0
  = (X1-X0, Y1-Y0)
```

物料坐标到电机目标坐标的直接映射角度为：

```text
θ = atan2(Y1-Y0, X1-X0)
```

该 `θ` 已经包含载物台的实际运动方向。因此后续使用标准旋转矩阵，不再额外添加负号或 `180°` 修正。

## 3. 标准齐次变换

二维标准旋转矩阵为：

```text
       ┌ cosθ  -sinθ ┐
R(θ) = │             │
       └ sinθ   cosθ ┘
```

从物料坐标到电机绝对目标坐标的齐次变换矩阵为：

```text
      ┌ cosθ  -sinθ   X0 ┐
Hew = │ sinθ   cosθ   Y0 │
      └  0       0     1 │
```

客户测点写成齐次坐标：

```text
Pwh = (xw,yw,1)ᵀ
```

电机绝对目标坐标通过一次矩阵乘法得到：

```text
┌ Xtarget ┐         ┌ xw ┐
│ Ytarget │ = Hew · │ yw │
└    1    ┘         └  1 │
```

展开为：

```text
Xtarget = X0 + xw·cosθ - yw·sinθ
Ytarget = Y0 + xw·sinθ + yw·cosθ
```

## 4. `(45,45)` 示例

假设示教结果为：

```text
Q0 = (320,180)
P1 = (100,0)
Q1 = (220,180)
```

则：

```text
θ = atan2(180-180, 220-320)
  = 180°
```

齐次矩阵为：

```text
      ┌ -1   0   320 ┐
Hew = │  0  -1   180 │
      └  0   0     1 │
```

客户要求测量：

```text
Pw = (45,45)
```

计算结果：

```text
Xtarget = 320 - 45 = 275
Ytarget = 180 - 45 = 135
```

软件直接向运动控制器发送最终目标 `(275,135)`，到位后触发激光测量；不需要先移动到 `Q0=(320,180)`。

## 5. 运行流程

```text
物料通过三销安装
  ↓
读取已示教并保存的 Hew
  ↓
接收客户测点 Pw
  ↓
执行一次齐次矩阵乘法
  ↓
发送一次最终电机绝对目标坐标
  ↓
到位后触发激光测量
```
